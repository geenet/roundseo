WHAT YOU NEED:
==============

1. Cloudflare Account (free or paid)
   → Sign up at cloudflare.com

2. wrangler CLI installed
   → Run: npm install -g wrangler

3. Cloudflare authentication
   → Run: wrangler login

4. Google OAuth credentials (optional for initial test)
   → Get from Google Cloud Console (can add later)

5. Your domain (optional for initial test)
   → Can test with cloudflare.workers.dev first


DEPLOY IN 3 STEPS:
==================

Step 1: Authenticate with Cloudflare
─────────────────────────────────────
npm install -g wrangler
wrangler login


Step 2: Run automated deployment
───────────────────────────────
cd /Users/g/code/github/geenet/roundseo
./scripts/DEPLOY_NOW.sh

(This runs: ./scripts/auto-deploy.sh)


Step 3: Test it's working
─────────────────────────
curl https://roundseo-api-production.YOUR_DOMAIN.workers.dev/health

Should respond: {"status":"ok","timestamp":"..."}

TROUBLESHOOTING:
================

"wrangler not found"
→ npm install -g wrangler

"Not authenticated"
→ wrangler login

"Database creation failed"
→ Check Cloudflare account has permissions

"Deploy failed"
→ Check wrangler.toml is properly formatted
→ Run: npm run build (to verify code builds)

"Migrations failed"
→ Check database was created
→ Run: wrangler d1 list
